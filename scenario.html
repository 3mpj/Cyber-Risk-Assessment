Cyber Threat Scenarios

Explore real-world cyber threat scenarios, understand the NIST Cybersecurity Framework (CSF) approach, and learn best practices for mitigation and response.

Ransomware Attack

A level 5 healthcare organization is hit by a ransomware attack after the Chief Medical Officer downloaded a malware that encrypted patient records and critical systems. The attackers demand a hefty ransom, threatening to leak sensitive data. All hospital operations are halted, and lives may be at risk if systems aren't restored quickly. The organization must act fast to mitigate the impact.

CSF Steps

🕵️Identify: Map critical assets, vulnerabilities, and potential impacts of ransomware across the organization.
🔒Protect: Implement access control, regular backups, and employee training to prevent unauthorized access.
🔍Detect: Monitor and detect unusual file activity to identify early stages of ransomware.
⚠️Respond: Contain the infection, isolate affected systems, notify stakeholders, and consult with law enforcement.
🔄Recover: Restore data from backups, reassess security, and review defenses to prevent future attacks.

Denial of Service (DoS) Attack

A retail company's online store faces a massive influx of illegitimate traffic, causing the server to crash and the website to become inaccessible to legitimate customers. This coordinated DoS attack by a known hacktivist group results in significant revenue loss and a damaged reputation, prompting the need for effective defensive strategies.

CSF Steps

🕵️Identify: Assess critical assets, services, and points of vulnerability for DoS attacks.
🔒Protect: Implement rate limiting, load balancing, and firewall rules to mitigate DoS risks.
🔍Detect: Monitor for unusual traffic patterns indicating a potential DoS attack.
⚠️Respond: Block malicious IPs, reroute traffic, and alert incident response teams.
🔄Recover: Reassess network configurations, enhance detection methods, and test backup servers.

Man-in-the-Middle Attack

During an important conference call with the finance team, a hacker intercepts the communication, altering transaction instructions without detection. The organization risks losing confidential data and faces potential financial loss, highlighting the need for secure communications and network monitoring.

CSF Steps

🕵️Identify: Assess network architecture & identify points of vulnerability in communications pathways. Map out critical assets that transmit sensitive data over the network.
🔒Protect: Use encryption for all network communications, implement VPNs, and enable mutual authentication to protect against unauthorized interception.
🔍Detect: Set up anomaly detection for unusual access patterns and monitor for irregularities in data traffic that may indicate interception.
⚠️Respond: Isolate affected communications, revoke any compromised credentials, and establish secure channels for ongoing communications.
🔄Recover: Restore secure communication channels, perform system and software updates, and conduct a post-incident review to enhance future defenses.

Phishing Attack

An employee receives an email from a supposed IT administrator requesting password changes. Without realizing, they submit login credentials, allowing attackers access to sensitive files.

CSF Steps

🕵️Identify: Recognize which departments and employees are at the highest risk of phishing attacks. Conduct regular risk assessments and evaluate access privileges for sensitive data.
🔒Protect: Implement email filtering solutions, conduct routine employee training on phishing awareness, and use multi-factor authentication (MFA) to protect accounts.
🔍Detect: Monitor for suspicious email activity and unauthorized login attempts. Deploy phishing detection tools to identify and block malicious emails.
⚠️Respond: Immediately disable compromised accounts, notify affected employees, and block malicious email sources.
🔄Recover: Reinforce anti-phishing training programs, review and update email security protocols, and assess any data loss or unauthorized access.

Insider Threat Attack

Kamau, is a disgruntled, overworked and underpaid employee with administrative access, he takes advantage of his system privileges and begins altering files and deleting important records.

CSF Steps

🕵️Identify: Identify critical assets and users with privileged access. Conduct regular audits on access controls and monitor employee role changes.
🔒Protect: Enforce least privilege principles, monitor high-risk user activities, and implement data loss prevention (DLP) tools.
🔍Detect: Utilize insider threat detection software to monitor for unusual behaviors, such as unauthorized data access or downloads.
⚠️Respond: Investigate and isolate insider threats immediately, revoke access for individuals displaying suspicious behavior, and notify relevant stakeholders.
🔄Recover: Adjust access policies and privileges, re-evaluate user access levels, and refine insider threat detection capabilities.

SQL Injection Attack

A hacker exploits a vulnerable input field on the organization's website, injecting malicious SQL commands to access the entire customer database.

CSF Steps

🕵️Identify: Identify and catalog all web applications and input fields that interact with databases. Review coding practices for potential SQL vulnerabilities.
🔒Protect: Implement input validation and sanitization for all user inputs, enforce least privilege access for database accounts, and regularly update software to patch known vulnerabilities.
🔍Detect: Monitor for unusual database query patterns and log all SQL interactions for signs of injection attempts.
⚠️Respond: Block malicious IPs, isolate affected databases, and update database credentials if compromise is detected.
🔄Recover: Revalidate database security settings, update web applications with secure code practices, and conduct security audits to prevent future injections.
